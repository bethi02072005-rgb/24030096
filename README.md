# Dám thất bại — Cảm nhận sách

Website tĩnh giới thiệu cảm nhận cá nhân về cuốn *Dám thất bại* của Billi P. S. Lim.

## Chạy trên máy

Mở `index.html` bằng trình duyệt. Không cần cài đặt hay build.

## Đưa lên GitHub Pages

1. Tạo repository mới trên GitHub và tải các tệp trong thư mục này lên.
2. Mở **Settings → Pages**.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main`, thư mục `/(root)`, rồi nhấn **Save**.
5. Chờ GitHub Pages hoàn tất và mở đường dẫn được hiển thị trong mục Pages.

Trang dùng `index.html` làm trang chính, `style.css` cho giao diện và `script.js` cho JavaScript. Font chữ được tải từ Google Fonts; nếu không có kết nối mạng, trang sẽ tự dùng font dự phòng.
